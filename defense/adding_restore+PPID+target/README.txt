1. analyzer.c : 행위 분석 모듈
파일 시스템에서 발생하는 모든 연산의 위험도를 수치화하여 악성 여부를 판단

A. 주요 기능 및 로직
1. 고엔트로피 암호화 탐지
-기능: calculate_entropy()를 호출하여 데이터의 무작위성을 측정하고, 엔트로피가 7.0을 초과하는 경우를 '암호화 의심' 상태로 정의
-오탐 방지: 엔트로피가 높더라도 is_valid_file_header() 함수를 통해 정상적인 파일 헤더(Magic Number)가 존재하는지 검증
-판단: (Entropy > 7.0) AND (Header Not Found) 조건이 성립하면 즉시차단

//주목할만한 포인트
2. 저엔트로피 우회 탐지
-기능: count_unique_bytes() 함수를 통해 데이터 내 고유 문자 개수를 카운트
- 판단: 1MB 이상의 대용량 쓰기임에도 고유 문자가 2개 이하(예:AAAAA)라면 저엔트로피 우회로 간주하여 즉시 차단

3. 대용량 쓰기 탐지
-기능: 데이터 내용과 무관하게, 단일 write 요청 크기가 10MB를 초과하면 공격으로 간주

4. 행위별 가중치 정책
-기능 : 고위험, 저위험도 행위를 분류하여 가중치를 다르게 부여

B. 보안적 의의
단순 엔트로피 탐지 방식이 가진 오탐(정상 파일 차단)과 미탐(저엔트로피 공격 허용)의 한계를 극복

----------

2. blue2.c : FUSE 시스템
실제 파일 시스템 접근 제어와 방어 조치를 수행

A. 주요 기능 및 로직
1. FUSE 인터페이스 구현
-기능: 핵심 시스템 콜을 핸들링하여, 모든 파일 접근 요청을 가로챔

2.PID 기반 상태 추적
-기능: g_score_table을 이용하여 프로세스 ID(PID)별로 악성 점수(Malice Score)를 누적 관리
-능동적 차단: 매 연산 시점마다 if (score >= KILL_THRESHOLD)를 검사하여, 임계치(150점) 초과 시 kill(pid, SIGKILL)을 호출하여 공격 프로세스를 즉시 강제 종료

B. 보안적 의의
백그라운드에서 모든 프로세스를 감시하고 통제하는 '보안 샌드박스' 역할을 수행

-----------

3. entropy.c : 수학적 도구 모듈
A. 주요 기능
1. 섀넌 엔트로피(Shannon Entropy) 계산: 입력받은 바이너리 데이터의 바이트 분포 확률을 계산하고 엔트로피 계산 공식을 활용하여 0.0~8.0 사이의 수치로 정량화

B. 보안적 의의
파일이 암호화되었는지(7.9 이상) 여부를 판단하는 객관적인 지표를 제공

----------

4. file_size_tracker.c : 파일 변형 탐지 모듈

//주목할만한 포인트
A. 주요 기능
1. Wiper(파괴) 탐지: 파일의 크기가 원본 대비 10% 미만으로 급감하는 경우를 탐지하여 차단
2. Base64 인코딩 탐지: 파일의 크기가 원본 대비 약 4/3배 변화하는 패턴을 감지하여 차단 

B. 보안적 의의
엔트로피 분석만으로는 놓칠 함

----------

5. restore.c : 데이터 복구 모듈

A. 주요 기능
1. Copy-on-Write: 원본 파일을 안전한 격리 구역(restore_backup)에 백업
2. 자동 복구: 공격이 탐지되어 프로세스가 차단되면, 즉시 백업된 원본 파일로 덮어씌워 데이터 손실이 없도록 함

B. 보안적 의의
공격을 막는 것을 넘어, 복원력을 시스템에 부여
